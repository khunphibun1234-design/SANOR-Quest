## ผลต่อการออกแบบเมื่อห้องเรียนมี 50 คน
- เล่นบนมือถือของนักเรียนเป็นหลัก ต้องลื่นบนเครื่องราคาประหยัด และเล่นออฟไลน์ได้
- ห้องจะเสียงดัง: งานพูดต้องมีทางเลือก "อัดเสียงแล้วฟังเอง" และปุ่มข้ามเสมอ
- แดชบอร์ดครูต้องอ่านง่ายเมื่อมีนักเรียน 50 คนต่อห้อง: เรียงตามคนที่ต้องช่วยก่อน และมีสรุปคำที่ทั้งห้องพลาด
- การเข้าระบบต้องเร็ว: ใช้รหัสห้อง + เลขที่ + PIN 4 หลัก ไม่ต้องใช้อีเมล

## ขั้นตอนผลิตแต่ละ Map
1. **ร่างเนื้อหา** (Claude): คำศัพท์ ประโยค บทพูด คำใบ้ และคำแปลไทย ลง `content/worlds/xx.json` พร้อมเล่นได้โดยใช้เสียงสังเคราะห์ชั่วคราว
2. **ตรวจเนื้อหา** (ผู้เชี่ยวชาญ): ตรวจจากเอกสารรายการเนื้อหาที่ระบบสร้างให้ · แก้ไขจนอนุมัติ
3. **บทอัดเสียง** (ระบบสร้างให้): ไฟล์รายการประโยคพร้อมชื่อไฟล์ที่ต้องใช้ เช่น `02-m1-03.mp3`
4. **ส่งไฟล์เสียง** (เจ้าของโครงการ): Claude ตรวจว่าครบทุกประโยคและชื่อไฟล์ถูกต้อง แล้วนำเข้าเกม
5. **ทดลองในห้องเรียน** → เก็บผล → แก้ไข
