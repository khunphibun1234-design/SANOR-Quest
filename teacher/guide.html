🎬 ดูวิดีโอคู่มือครู 2 นาที (มีเสียงพากย์)

ก่อนคาบแรก (10 นาที)

  1. เปิด …/teacher/ → สมัครใช้งาน → + สร้างห้อง (เช่น ม.2/5) จะได้ รหัสห้อง 6 ตัว
  2. แจก แบบฟอร์มยินยอมผู้ปกครอง (หน้าแรกของเกม → แบบฟอร์มยินยอมผู้ปกครอง)
  3. แท็บ ตั้งค่าห้อง: เลือกโลกที่เปิด, ระดับตัวช่วยภาษาไทย (แนะนำ 🌱 Starter ช่วงแรก), เปิด แบบทดสอบก่อนเรียน

คาบแรก

  1. นักเรียนเปิดเกมบนมือถือ (Chrome) → หน้า Splash กด Start → Create an account (ครั้งแรก) → ใส่รหัสห้อง + เลขที่ + ชื่อเล่น + PIN 4 หลัก (ให้จดไว้)
  2. ทำ 📝 Pre-test 20 ข้อ (≈15 นาที) ทำได้ครั้งเดียว
  3. เริ่ม Map 01 ภารกิจ 1 แนะนำให้ติดตั้งแอป (📲 Install app) เพื่อเล่นได้แม้ไม่มีเน็ต

ระหว่างคาบ (ห้อง 50 คน)

  • ใส่หูฟังถ้ามี · ห้องเสียงดังให้ใช้ “✓ I said it” หรือ “Skip” ในงานพูด
  • ไม่มีเน็ตก็เล่นได้ ผลจะส่งเองเมื่อออนไลน์ (สถานะดูใน My passport)
  • เปิดแดชบอร์ด กด ↻ รีเฟรช ดูแถว แถบสีส้ม = ตอบถูกครั้งแรก < 50% เดินไปช่วยก่อน
  • เครื่องที่ใช้ร่วมกัน: เมื่อเปลี่ยนคน ให้ My passport → Leave this class → OK เพื่อล้างเครื่อง

หลังคาบ

  • แท็บ คำที่พลาดบ่อย: 10 คำ/ประโยคที่ทั้งห้องพลาด ใช้ทบทวนต้นคาบหน้า
  • มอบหมาย 🔁 ทบทวนประจำวัน 3 นาที เป็นการบ้าน
  • ⬇ ส่งออก CSV เก็บคะแนน · 🖨 พิมพ์รายงาน · ดูรายคนที่ “ดูรายละเอียด”

ปลายภาค

  • ตั้งค่าห้อง → เปิด แบบทดสอบหลังเรียน แล้วดูแท็บ ก่อน/หลังเรียน (คะแนนเฉลี่ยก่อน → หลัง)
  • ส่งออก CSV แล้ว ลบห้อง เมื่อจบปีการศึกษา (PDPA)

ปัญหาที่พบบ่อย

  • ลืม PIN / ถูกล็อก: ดูรายละเอียดนักเรียน → ตั้ง PIN ใหม่
  • เกมกระตุก: ปิดแอปอื่น เกมลดความละเอียดภาพให้เองอัตโนมัติ · มือถือไม่รองรับ 3D ใช้แบบฝึก 2D (ลิงก์ในหน้าเริ่มภารกิจ)
  • ไมค์ไม่ทำงาน: การตรวจด้วยไมค์ปิดไว้เป็นค่าเริ่มต้นเพื่อความเป็นส่วนตัว เปิดได้ใน My passport (เมื่อผู้ปกครองยินยอม)
  • เข้าห้องไม่ได้: ตรวจรหัสห้อง (ไม่มีตัว O/0, I/1) และเลขที่ 1–99
